# murzins-telegram-mcp

Персональный MCP-сервер Telegram для Claude: работа с ботами, чтение и поиск по своим
чатам. Работает от вашего собственного аккаунта, это не бот: видит те же чаты и группы,
что и вы, никого добавлять в чаты не нужно. У каждого члена семьи своя копия и своя сессия.

## Инструменты

| Инструмент | Что делает | Доступ |
|---|---|---|
| `tg_bot_history` | последние сообщения в чате с ботом, с кнопками и файлами | только боты |
| `tg_bot_send` | отправить боту текст или команду и дождаться ответа | только боты |
| `tg_bot_press` | нажать обычную кнопку под сообщением бота | только боты |
| `tg_chats` | список чатов, свежие сверху, с фильтром по названию | при `TG_READ_ENABLED=true` |
| `tg_messages` | сообщения одного чата, листание назад, поиск внутри | при `TG_READ_ENABLED=true` |
| `tg_search` | поиск по тексту во всех чатах или в одном | при `TG_READ_ENABLED=true` |

## Что сервер не делает никогда

- не пишет людям, в группы и каналы: отправка и нажатия только в чатах с ботами;
  юзернейм проверяется на окончание `bot`, а аккаунт — на флаг бота;
- не нажимает оплату, запрос телефона и геолокации, мини-приложения и кнопки
  с подтверждением паролем; кнопка-ссылка возвращает адрес и ничего не открывает;
- не отмечает сообщения прочитанными, не удаляет, не пересылает, не скачивает файлы;
- не показывает список контактов.

Дополнительно: белый список ботов `TG_ALLOWED_BOTS` и список закрытых для чтения
чатов `TG_READ_DENIED_CHATS`. Чтение включено в шаблоне `.env.example`; при
`TG_READ_ENABLED=false` инструменты чтения не регистрируются, а модель получает
подсказку, как их включить.

Чат в `tg_messages` и `tg_search` можно указать названием, как он виден в Telegram,
`@username` или id из `tg_chats`.

## Установка

```bash
make install
make env        # создаст .env.local из шаблона с правами 600
```

Впишите в `.env.local` ключи `TG_API_ID` и `TG_API_HASH` с
https://my.telegram.org/apps (API development tools). Одни ключи можно использовать
на всю семью: они описывают приложение, а не человека.

```bash
make login      # телефон, код из Telegram, облачный пароль; сессия пишется в .env.local
make doctor     # проверка без вывода секретов
make register   # подключить сервер к Claude Code; затем перезапустить сессию
```

Отключить доступ в любой момент: Telegram → Настройки → Устройства → `murzins-telegram-mcp`.

## Секреты

Сессия Telegram даёт полный доступ к аккаунту. Она хранится только в `.env.local`:

- `.gitignore` работает по белому списку, `.env.local` и `*.session` в git не попадают;
- `tests/unit/test_no_secrets.py` проверяет все файлы под git на строку сессии,
  `api_hash` и номера телефонов; запускается в `make test` и в pre-commit (`make hooks`);
- настройки хранят секреты в `SecretStr` и не печатают их в логах и `repr`.
